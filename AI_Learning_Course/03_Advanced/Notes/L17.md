📖 工具调用的概念

**什么是工具调用？**

  * 工具调用是指让AI自主判断何时需要调用工具，以及如何串联多个工具
  * 工具调用的核心是"判断边界 → 选工具 → 串联调用 → 检查结果 → 失败兜底"
  * 工具调用的优势是"突破AI知识局限，扩展AI能力边界"



**为什么需要工具调用？**

  * AI很强大，但不会上网查最新信息、不能精确计算、不能直接读写文件
  * 工具调用可以让AI突破自身知识局限，扩展能力边界
  * 工具调用可以让AI连接任何数据源和工具



**关键认知：** 工具调用 = AI输出"调用指令"（JSON）→ 程序执行 → 结果返回给AI。AI是"指挥官"，不是"执行者"。 

📖 工具调用方法

**方法五步法：**

  * **步骤1：判断边界** — 判断任务是否需要调用工具
  * **步骤2：选工具** — 选择合适的工具
  * **步骤3：串联调用** — 串联多个工具调用
  * **步骤4：检查结果** — 检查工具调用的结果
  * **步骤5：失败兜底** — 设计失败兜底方案



**提示词模板：**

**重要认知：** 工具调用不是"可有可无"，而是"必须掌握"。工具调用能让AI突破自身知识局限，扩展能力边界。 

📖 多工具串联和失败兜底

**多工具串联方法：**

  * **方法1：顺序串联** — 按顺序调用多个工具
  * **方法2：条件串联** — 根据条件选择调用哪个工具
  * **方法3：循环串联** — 循环调用同一个工具



**失败兜底方法：**

  * **方法1：重试** — 失败后重试
  * **方法2：降级** — 失败后降级到备用方案
  * **方法3：人工介入** — 失败后人工介入



**关键认知：** 多工具串联和失败兜底不是"可有可无"，而是"必须执行"。只有通过多工具串联和失败兜底，才能保证工具调用的可靠性。

##### 🧠 认知加油站：Function Calling — AI如何"打电话"叫工具？（3分钟）

讲师讲解：

在总结之前，我们补充一个底层认知：**AI到底是怎么"调用工具"的？它真的会"操作"别的程序吗？**

实际上，AI并不会真的"操作"任何东西。Function Calling的流程是**三步骤** ：

  1. **AI输出结构化数据** （如JSON格式：{"function": "calculator", "params": {"a": 3847, "b": 6291, "op": "multiply"}}）——AI只是"说"出了它想调用什么工具，不是真的调用了
  2. **外层程序接收这个JSON** ，真正执行工具调用（运行计算器、查数据库、读文件）
  3. **工具的执行结果** 被注入回对话上下文，AI基于这个结果继续生成回复



**打个比方：** AI就像一个"不会走路但会说话的人"。它不能自己去拿快递，但它可以**口头告诉你** "请去门口拿快递，取件码是1234"。你去拿了快递，然后把包裹内容告诉它，它再基于内容继续工作。**AI负责"说"，外层程序负责"做"。**

**一句话记住：** Function Calling = AI输出"调用指令"（JSON）→ 程序执行 → 结果返回给AI。AI是"指挥官"，不是"执行者"。

##### 🧠 认知加油站：MCP协议 — AI的"USB-C接口"（4分钟）

讲师讲解：

我们刚才学了Function Calling——AI通过JSON"说出"要调用什么工具。但有个问题：**每个AI平台、每个工具都有自己的"接口格式"，互不兼容。就像早年每个手机都要用不同的充电线。**

这就是**MCP（Model Context Protocol，模型上下文协议）** 要解决的问题。MCP由Anthropic于2024年11月推出，被业界称为**"AI的USB-C接口"** ——只要设备和接口兼容，插上就能用。

**MCP的三大核心概念：**

  1. **MCP Server（工具提供方）** ：把工具（如文件系统、数据库、API）封装成标准的"MCP服务"，就像USB设备
  2. **MCP Client（AI调用方）** ：AI通过统一的MCP协议发现和调用这些服务，就像USB主机
  3. **Transport（通信协议）** ：定义Client和Server之间怎么传数据（stdio/HTTP），就像USB线缆



**打个比方：** Function Calling是"每个设备自带专用接口"——电视用HDMI、打印机用USB-B、手机用Lightning。MCP是"统一Type-C"——所有设备一个接口，省去适配的麻烦。

**一句话记住：** MCP = AI工具的"统一接口标准"。学会MCP，你就能让AI连接任何数据源和工具，而不用为每个平台写单独的适配代码。
