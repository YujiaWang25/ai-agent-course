#### 项目B实战深化①：代码重构 — 从"能跑"到"好代码"

40分钟 · 新增 项目B

##### Part 1：开场导入（5分钟）

讲师开场：

你的Markdown转Word工具已经能跑了。但"能跑"和"好代码"之间还有很大距离。今天我们要学**代码重构** ——在功能不变的前提下，让代码更清晰、更易维护、更少bug。

##### Part 2：识别代码异味（8分钟）

讲师讲解：

常见的"代码异味"（Code Smell）：

  * **重复代码：** 同样的逻辑出现在多个地方
  * **过长函数：** 一个函数做了太多事，难以理解和测试
  * **魔法数字：** 代码中直接写死的数字，不知道含义
  * **硬编码：** 路径、配置等直接写在代码里，换个环境就跑不了
  * **命名不清晰：** 变量名像"x"、"temp"、"data"，不知道存了什么



##### Part 3：实操 — 用AI重构你的MD转Word工具（15分钟）

讲师指令：

请用以下提示词，让AI帮你重构代码：

请帮我重构以下Markdown转Word的Python代码。要求： 1\. 将长函数拆分成多个小函数（每个函数只做一件事） 2\. 消除重复代码，提取公共逻辑 3\. 将硬编码的配置（如字体大小、颜色）提取为常量 4\. 改进变量命名，让代码"自解释" 5\. 添加必要的注释，解释"为什么这样做"而不是"做了什么" 重构后，请说明： \- 拆分了哪些函数？ \- 消除了哪些重复？ \- 命名做了哪些改进？ [贴上你的代码]

##### Part 4：重构前后对比（7分钟）

讲师讲解：

引导学生对比重构前后的代码：

  * **代码行数：** 重构后可能更多（因为拆分），但每行更清晰
  * **可读性：** 重构后能否"一眼看懂"每个函数做什么？
  * **可测试性：** 重构后能否单独测试每个小函数？
  * **可扩展性：** 如果要加新功能，重构后是否更容易？



##### 📚 自学补充：代码重构深度解析（15分钟）

自学目标：

通过本节自学，你将能够：① 理解代码重构的概念和重要性；② 掌握常见的代码异味及其识别方法；③ 学会用AI进行代码重构并验证。

📖 代码重构的概念

**什么是代码重构？**

  * 代码重构是指在功能不变的前提下，让代码更清晰、更易维护、更少bug
  * 核心：不改功能，只改结构
  * 目标：让代码"更容易理解、更容易修改、更不容易出错"



**为什么需要代码重构？**

  * "能跑"和"好代码"之间还有很大距离
  * 代码异味会导致维护成本越来越高
  * 重构可以提高代码的可读性、可测试性和可扩展性



**关键认知：** 代码重构 = 不改功能，只改结构。目标是让代码"更容易理解、更容易修改、更不容易出错"。 

📖 常见的代码异味

**代码异味1：重复代码**

  * 定义：同样的逻辑出现在多个地方
  * 问题：修改时需要改多处，容易遗漏
  * 解决：提取公共函数或类



**代码异味2：过长函数**

  * 定义：一个函数做了太多事，难以理解和测试
  * 问题：难以理解、难以测试、难以修改
  * 解决：拆分成多个小函数，每个函数只做一件事



**代码异味3：魔法数字**

  * 定义：代码中直接写死的数字，不知道含义
  * 问题：难以理解、难以修改
  * 解决：提取为常量，并命名清晰



**代码异味4：硬编码**

  * 定义：路径、配置等直接写在代码里，换个环境就跑不了
  * 问题：不灵活、难以维护
  * 解决：提取为配置文件或环境变量



**代码异味5：命名不清晰**

  * 定义：变量名像"x"、"temp"、"data"，不知道存了什么
  * 问题：难以理解代码意图
  * 解决：使用有意义的命名，让代码"自解释"



**重要认知：** 代码异味不是"错误"，而是"坏味道"。它们不会导致程序崩溃，但会让代码越来越难维护。识别代码异味是重构的第一步。 

📖 用AI进行代码重构

**重构步骤：**

  1. **分析代码：** 识别代码异味
  2. **制定计划：** 确定重构方案
  3. **执行重构：** 用AI帮助重构
  4. **验证功能：** 确保重构后功能不变



**AI重构提示词模板：**

请帮我重构以下代码。要求： 1\. 将长函数拆分成多个小函数（每个函数只做一件事） 2\. 消除重复代码，提取公共逻辑 3\. 将硬编码的配置提取为常量 4\. 改进变量命名，让代码"自解释" 5\. 添加必要的注释，解释"为什么这样做"而不是"做了什么" 重构后，请说明： \- 拆分了哪些函数？ \- 消除了哪些重复？ \- 命名做了哪些改进？ [贴上你的代码]

**关键认知：** 用AI进行代码重构可以大大提高效率，但重构后的代码需要验证。核心原则：重构后功能不变。 

##### 💡 更多案例：代码重构实战案例（10分钟）

案例1：重复代码重构

**任务：** 消除重复代码

重构前： def process_order(order): # 计算运费 if order['weight'] > 5: shipping = order['weight'] * 1.5 else: shipping = 5 # 计算税费 tax = order['amount'] * 0.08 # 计算总价 total = order['amount'] + shipping + tax return total def process_refund(order): # 计算运费（重复代码） if order['weight'] > 5: shipping = order['weight'] * 1.5 else: shipping = 5 # 计算税费（重复代码） tax = order['amount'] * 0.08 # 计算退款金额 refund = order['amount'] + shipping + tax return refund 重构后： def calculate_shipping(weight): return weight * 1.5 if weight > 5 else 5 def calculate_tax(amount): return amount * 0.08 def process_order(order): shipping = calculate_shipping(order['weight']) tax = calculate_tax(order['amount']) return order['amount'] + shipping + tax def process_refund(order): shipping = calculate_shipping(order['weight']) tax = calculate_tax(order['amount']) return order['amount'] + shipping + tax 改进：提取公共函数，消除重复代码

**适用场景：** 消除重复逻辑

案例2：过长函数重构

**任务：** 拆分过长函数

重构前： def generate_report(data): # 计算统计数据 total = sum(data) avg = total / len(data) max_val = max(data) min_val = min(data) # 格式化报告 report = f"""报告 ====== 总数：{total} 平均值：{avg} 最大值：{max_val} 最小值：{min_val}""" # 保存报告 with open('report.txt', 'w') as f: f.write(report) return report 重构后： def calculate_statistics(data): return { 'total': sum(data), 'avg': sum(data) / len(data), 'max': max(data), 'min': min(data) } def format_report(stats): return f"""报告 ====== 总数：{stats['total']} 平均值：{stats['avg']} 最大值：{stats['max']} 最小值：{stats['min']}""" def save_report(report, filename='report.txt'): with open(filename, 'w') as f: f.write(report) return report def generate_report(data): stats = calculate_statistics(data) report = format_report(stats) return save_report(report) 改进：拆分成三个小函数，每个函数只做一件事

**适用场景：** 拆分复杂函数

案例3：命名不清晰重构

**任务：** 改进变量命名

重构前： def func(x, y): a = x + y b = x * y c = a / b return c 重构后： def calculate_ratio(sum_value, product_value): ratio = sum_value / product_value return ratio 改进：使用有意义的命名，让代码"自解释"

**适用场景：** 提高代码可读性
