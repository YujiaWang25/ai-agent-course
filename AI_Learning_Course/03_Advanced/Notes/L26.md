#### Agentic框架认知：LangChain、LangGraph、LlamaIndex全景

40分钟 · 新增 AI认知

##### Part 1：开场导入（5分钟）

讲师开场：

到目前为止，我们都是"手写提示词"来构建Agent。但在实际开发中，有一整套**框架** 可以帮助你更高效地构建Agent。今天我们要了解三个最主流的框架，知道它们各自适合什么场景。

##### Part 2：LangChain — 链式调用的"瑞士军刀"（8分钟）

讲师讲解：

**LangChain的核心理念：** 把LLM操作抽象成"链（Chain）"——提示词模板 → LLM调用 → 输出解析 → 下一步操作，像搭积木一样串联起来。

**核心组件：**

  * **Prompt Templates：** 可复用的提示词模板
  * **Chains：** 多个组件串联的流水线
  * **Tools：** 封装好的工具接口（搜索、计算、API调用）
  * **Memory：** 对话记忆管理



**适合场景：** 快速原型、简单的LLM应用、RAG系统

##### Part 3：LangGraph — 状态机的"建筑师"（8分钟）

讲师讲解：

**LangGraph的核心理念：** Agent不是一条直线，而是一个**图（Graph）** ——有节点（Node）、有边（Edge）、有状态（State），可以循环、分支、条件跳转。

**核心概念：**

  * **Node：** 一个处理步骤，比如"调用LLM"或"执行工具"
  * **Edge：** 节点之间的连接，决定流程走向
  * **State：** 全局状态，贯穿整个流程
  * **Conditional Edge：** 根据条件选择不同路径



**适合场景：** 复杂Agent工作流、多Agent协作、需要循环和条件判断的场景

##### Part 4：LlamaIndex — 数据索引的"图书馆员"（7分钟）

讲师讲解：

**LlamaIndex的核心理念：** 专注于**数据连接** ——把各种数据源（文档、数据库、API）结构化地"喂"给LLM。

**核心能力：**

  * **数据加载：** 支持PDF、网页、数据库等100+种数据源
  * **索引构建：** 向量索引、关键词索引、知识图谱索引
  * **查询引擎：** 自然语言查询 → 检索 → 合成回答



**适合场景：** 知识库问答、文档分析、企业知识管理

##### Part 5：框架选型决策（7分钟）

讲师讲解：

场景| 推荐框架| 理由  
---|---|---  
简单LLM对话+工具调用| LangChain| 上手快，生态丰富  
复杂Agent工作流| LangGraph| 状态管理强，支持循环和条件  
知识库/RAG系统| LlamaIndex| 数据索引能力最强  
零基础快速搭建| Coze / Dify| 低代码，无需编程  
  
**核心认知：** 框架不是"学得越多越好"，而是"知道什么时候用什么"。就像你不会用挖掘机来挖一个花盆。

##### 💡 更多案例：Agentic框架实战案例（10分钟）

案例1：LangChain快速原型

**任务：** 使用LangChain快速搭建一个简单的问答系统

请使用LangChain搭建一个简单的问答系统： 步骤1：安装LangChain pip install langchain langchain-openai 步骤2：创建提示词模板 from langchain.prompts import PromptTemplate template = "请回答以下问题：{question}" prompt = PromptTemplate.from_template(template) 步骤3：创建Chain from langchain.chains import LLMChain chain = LLMChain(llm=llm, prompt=prompt) 步骤4：执行Chain response = chain.run("什么是人工智能？") print(response)

**适用场景：** 快速原型、简单的LLM应用

案例2：LangGraph复杂工作流

**任务：** 使用LangGraph设计一个客服Agent工作流

请使用LangGraph设计一个客服Agent工作流： 节点定义： \- start：接收用户问题 \- classify：分类问题类型 \- handle_refund：处理退款 \- handle_inquiry：处理咨询 \- handle_complaint：处理投诉 \- end：结束 边定义： \- start → classify \- classify → handle_refund（如果类型是"退款"） \- classify → handle_inquiry（如果类型是"咨询"） \- classify → handle_complaint（如果类型是"投诉"） \- handle_refund → end \- handle_inquiry → end \- handle_complaint → end 状态定义： \- state = {"question": "", "type": "", "response": ""}

**适用场景：** 复杂Agent工作流、多Agent协作

案例3：LlamaIndex知识库

**任务：** 使用LlamaIndex构建一个文档问答系统

请使用LlamaIndex构建一个文档问答系统： 步骤1：安装LlamaIndex pip install llama-index 步骤2：加载文档 from llama_index import SimpleDirectoryReader documents = SimpleDirectoryReader('./data').load_data() 步骤3：构建索引 from llama_index import GPTVectorStoreIndex index = GPTVectorStoreIndex.from_documents(documents) 步骤4：查询 query_engine = index.as_query_engine() response = query_engine.query("文档的主要内容是什么？") print(response)

**适用场景：** 知识库问答、文档分析、企业知识管理
