#### Agent部署实战：从本地到云端

40分钟 · 新增 AI认知

##### Part 1：开场导入（5分钟）

讲师开场：

你的Agent在本地跑得很好。但别人怎么用？今天我们要学**如何把Agent部署到服务器上** ，让任何人通过API或网页访问它。这是Agent从"个人工具"到"服务产品"的最后一步。

##### Part 2：三种部署方式对比（8分钟）

讲师讲解：

方式| 优点| 缺点| 适合场景  
---|---|---|---  
**本地运行**|  零成本，完全可控| 只能自己用| 个人工具、原型验证  
**API服务化**|  别人可以通过API调用| 需要服务器、需要处理并发| 团队内部使用  
**云端部署**|  自动扩容、高可用| 成本较高、需要运维知识| 对外服务、商业产品  
  
##### Part 3：实操 — 将Agent包装为API服务（15分钟）

讲师指令：

请用以下提示词，让AI帮你把Agent包装成API：

请帮我将文本分类智能体包装成一个简单的Web API服务。要求： 1\. 使用Flask或FastAPI框架 2\. 提供一个POST接口 /classify，接收JSON： {"text": "需要分类的文本"} 3\. 返回JSON： {"category": "分类结果", "confidence": "置信度", "reasoning": "分类理由"} 4\. 添加错误处理：文本为空返回400，服务器错误返回500 5\. 添加简单的使用说明（如何启动服务、如何调用API） [贴上你的智能体代码]

##### Part 4：部署检查清单（7分钟）

讲师讲解：

部署前的检查清单：

  * ✅ API密钥安全：不要硬编码在代码里，使用环境变量
  * ✅ 速率限制：防止API被滥用
  * ✅ 日志记录：记录每次API调用的输入、输出、耗时
  * ✅ 健康检查：提供 /health 接口，返回服务状态
  * ✅ 错误处理：所有异常都有友好的错误信息



##### 🧠 理念应用：本节课的AI协作思维（3分钟）

讲师引导：

回顾本节课，我们在哪些地方体现了四大核心理念与八柱技能？

  * **🧠 理念1：思维方式转变** — 我们从"本地运行"升级到了"云端部署"的服务思维。**核心：** 建立"问题分析→定位→修正"的协作思维
  * **🎯 理念2：人驾驶AI工程体系** — 我们设计部署架构，AI以服务形式运行。**核心：** "流程设计→规则制定→结果审核"三步骤
  * **📝 理念3：输入质量决定输出** — 我们通过标准化API接口，让任何人都能正确使用服务。**核心：** "结构化描述→约束条件→格式规范"
  * **🛡️ 理念4：幻觉管理** — 我们通过安全检查和日志监控，确保服务稳定运行。**核心：** "边界定义→异常检测→回归测试"



**🔧 八柱技能落地：**

  * **📝 柱四（结构化表达）** — 我们用标准化的API文档结构化表达接口规范
  * **🛡️ 柱五（反向自证）** — 我们通过监控日志验证服务的运行状态
  * **🎯 柱八（模糊信号应激）** — 我们对服务异常有直觉判断，能快速定位问题



##### 📚 自学补充：Agent部署实战深度解析（15分钟）

自学引导：

**为什么要部署？**

本地运行的Agent只能自己使用，而部署后的Agent可以让任何人通过网络访问。部署是Agent从"个人工具"到"服务产品"的关键一步。

详细解释：

**三种部署方式对比：**

方式| 优点| 缺点| 适合场景  
---|---|---|---  
**本地运行**|  零成本，完全可控，隐私安全| 只能自己用，无法共享| 个人工具、原型验证  
**API服务化**|  别人可以通过API调用，成本适中| 需要服务器，需要处理并发| 团队内部使用、小型服务  
**云端部署**|  自动扩容、高可用、专业运维| 成本较高、需要运维知识| 对外服务、商业产品  
  
**API服务化的核心组件：**

  * **Web框架** ：Flask（轻量）或FastAPI（高性能）
  * **API接口** ：定义输入输出格式，支持RESTful规范
  * **错误处理** ：统一的错误响应格式，友好的错误信息
  * **安全防护** ：API密钥验证、速率限制、日志记录



学员操作指南：

**跟着做：将你的Agent包装为API服务**

  1. 打开你的结课项目智能体代码
  2. 安装Flask或FastAPI：pip install flask 或 pip install fastapi uvicorn
  3. 使用课程中的提示词，让AI帮你包装成API
  4. 启动服务：python app.py（Flask）或 uvicorn app:app --reload（FastAPI）
  5. 测试API： \- 使用curl：curl -X POST http://localhost:8000/classify -H "Content-Type: application/json" -d '{"text": "测试文本"}' \- 或使用Postman发送POST请求 
  6. 测试错误场景：空文本、超长文本等



更多案例：

**案例：API安全检查清单**

  * ✅ **API密钥安全** ：不要硬编码在代码里，使用环境变量
  * ✅ **速率限制** ：使用Flask-Limiter或FastAPI-Limiter限制请求频率
  * ✅ **日志记录** ：记录每次调用的输入、输出、耗时、用户ID
  * ✅ **健康检查** ：提供/health接口，返回服务状态和运行时间
  * ✅ **CORS配置** ：设置允许的跨域来源
  * ✅ **请求验证** ：验证输入参数的类型和范围

  4. 添加日志记录功能，记录每次API调用
