#### 实战初体验：Markdown转Word项目启动

40分钟 · 融合新增 项目B

##### Part 1：开场导入（5分钟）

讲师开场：

前面我们一直在学"通用技能"，今天我们要**正式启动一个真实项目** ——Markdown转Word工具。这个项目会贯穿整个课程，你将亲手经历"需求→开发→调试→优化→交付"的完整流程。而且这个项目**不需要你自己写代码** ——你是指挥官，AI是程序员。

##### Part 2：项目启动 — 环境搭建（10分钟）

讲师指令：

首先，我们需要让AI帮我们准备开发环境。请发送以下提示词：

我需要开发一个Markdown转Word的Python工具。请告诉我： 1\. 需要安装哪些Python库？（请给出具体的pip install命令） 2\. 如何验证安装是否成功？ 3\. 创建一个基本的项目结构（文件命名建议） 注意：我不需要你写转换代码，只需要帮我搭建环境。

讲师旁注：确保学生安装了python-docx库。如果遇到安装问题，让AI帮忙排查。

##### Part 3：第一版代码生成与测试（20分钟）

讲师指令：

现在请把第3课整理的需求文档发给AI，让它生成第一版代码。然后：

  1. **运行代码** ：用AI提供的命令运行，观察是否报错
  2. **检查输出** ：打开生成的Word文档，逐一检查：标题序号是否正确？字体是否仿宋？字号是否14pt？行距是否1.5倍？
  3. **记录问题** ：至少记录3个发现的问题，用第6课学的"三要素"格式描述



（20分钟，讲师巡视指导，收集常见问题）

**教学提示：** 第一版代码几乎100%有问题。告诉学生"这不是你的问题，这是AI协作的正常流程"。降低学生的挫败感。 

##### 📚 自学补充：AI协作开发深度解析（15分钟）

自学目标：

通过本节自学，你将能够：① 理解AI协作开发的流程；② 掌握项目环境搭建的方法；③ 学会代码测试和问题记录。

📖 AI协作开发流程

**流程五步法：**

  * **步骤1：需求分析** — 明确项目的需求、目标、约束
  * **步骤2：环境搭建** — 搭建开发环境，安装必要的库
  * **步骤3：代码生成** — 让AI生成第一版代码
  * **步骤4：测试验证** — 测试代码的功能，验证输出是否符合预期
  * **步骤5：问题记录** — 记录发现的问题，准备调试



**关键认知：** AI协作开发不是"一次到位"，而是"迭代优化"。每次都要测试代码的功能，记录发现的问题。 

📖 项目环境搭建

**环境搭建步骤：**

  * **步骤1：安装Python** — 安装Python开发环境
  * **步骤2：安装库** — 安装项目需要的库（如python-docx）
  * **步骤3：创建项目结构** — 创建项目文件夹和文件
  * **步骤4：验证安装** — 验证安装是否成功



**常用Python库：**

库名| 用途| 安装命令  
---|---|---  
python-docx| Word文档操作| pip install python-docx  
markdown| Markdown解析| pip install markdown  
pandas| 数据处理| pip install pandas  
openpyxl| Excel操作| pip install openpyxl  
  
**重要认知：** 环境搭建不是"可有可无"，而是"必须执行"。只有正确的环境才能保证代码正常运行。 

📖 代码测试和问题记录

**测试方法：**

  * **方法1：功能测试** — 测试代码的核心功能是否正常
  * **方法2：输出验证** — 验证输出是否符合预期
  * **方法3：边界测试** — 测试代码的边界情况



**问题记录方法：**

  * **方法1：三要素法** — 精确指出错误、说明正确的部分、提供期望vs实际对比
  * **方法2：Bug清单** — 记录所有发现的问题
  * **方法3：优先级排序** — 按优先级排序问题



**关键认知：** 代码测试和问题记录不是"可有可无"，而是"必须执行"。只有测试和记录过的代码才能保证质量。 

##### 💡 更多案例：AI协作开发实战案例（10分钟）

案例1：Markdown转Word项目

**需求分析：**

  * 任务目标：将Markdown文档转换为Word文档
  * 输入格式：Markdown文档
  * 输出格式：Word文档
  * 约束要求：字体仿宋_GB2312、字号14pt、行距1.5倍



**环境搭建：**

我需要开发一个Markdown转Word的Python工具。请告诉我： 1\. 需要安装哪些Python库？（请给出具体的pip install命令） 2\. 如何验证安装是否成功？ 3\. 创建一个基本的项目结构（文件命名建议） 注意：我不需要你写转换代码，只需要帮我搭建环境。

**代码生成：**

请根据以下需求生成Markdown转Word的Python代码： \- 字体：仿宋_GB2312 \- 字号：正文四号14pt \- 行距：1.5倍 \- 段落间距：段前段后0.5倍 \- 标题格式：一级标题小二加粗"一、"，二级标题三号加粗"（一）"，三级标题小三加粗"1、"，四级标题小三加粗"1.1、" \- 表格格式：宽度与正文一致、左右对齐、表格内文字四号、1倍行距 \- 替换半角引号为全角中文弯引号"" \- 去除MD标识，保留加粗语法**文本** \- 正文首行缩进两个全角空格

案例2：代码测试

**测试步骤：**

  * 运行代码：用AI提供的命令运行，观察是否报错
  * 检查输出：打开生成的Word文档，逐一检查格式
  * 记录问题：至少记录3个发现的问题



**检查项：**

  * 标题序号是否正确？
  * 字体是否仿宋？
  * 字号是否14pt？
  * 行距是否1.5倍？



案例3：问题记录

**问题1：标题序号错误**

精确指出错误：三级标题和四级标题不正确 说明正确的部分：1、2级标题正确，不用调整 提供期望vs实际对比：期望"一、..."，实际"1.1、..."

**问题2：首行缩进错误**

精确指出错误：首行缩进应该是2字符，但现在是4字符 说明正确的部分：其他格式（字体、字号、行距）都正确，不需要调整 提供期望vs实际对比：期望2字符，实际4字符

**问题3：表格格式错误**

精确指出错误：表格宽度与正文不一致 说明正确的部分：表格左右对齐正确 提供期望vs实际对比：期望宽度与正文一致，实际宽度不一致
