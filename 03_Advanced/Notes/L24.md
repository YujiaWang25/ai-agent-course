#### 校验工程：多文件标准化验证体系

40分钟 · 原有 AI认知

AI的输出，你能100%信任吗？**不能。** 我们需要一套"校验体系"——就像工厂的质检流程。今天学：**如何建立工程化的校验闭环。**

##### 📚 自学补充：校验工程深度解析（15分钟）

自学目标：

通过本节自学，你将能够：① 理解校验工程的概念和重要性；② 掌握校验工程的核心方法；③ 学会建立工程化的校验闭环。

📖 校验工程的概念

**什么是校验工程？**

  * 校验工程是指建立一套工程化的校验体系，用于验证AI输出的正确性
  * 校验工程的核心是"校验闭环"——标准答案 + AI输出 + 差异分析 + 迭代优化
  * 校验工程的优势是"系统性、可重复、可追溯"



**为什么需要校验工程？**

  * AI的输出不能100%信任，需要一套"校验体系"——就像工厂的质检流程
  * 校验工程可以系统性验证AI输出的正确性，提高AI的可靠性
  * 校验工程可以可重复验证AI输出的正确性，提高AI的稳定性



**关键认知：** 校验闭环 = 标准答案 + AI输出 + 差异分析 + 迭代优化。这是区分"Demo级Agent"和"生产级Agent"的关键能力。 

📖 校验工程的核心方法

**方法1：三方校验**

  * 定义：搭建"三方校验"——自己人工分类（标准答案）→ 让AI分类（AI输出）→ 对比差异 → 让AI分析差异原因 → 改进提示词
  * 适用场景：单文件验证、分类验证、结果验证
  * 示例：人工分类10个案例 → AI分类10个案例 → 对比差异 → 分析差异原因 → 改进提示词



**方法2：批量用例测试**

  * 定义：让AI生成10组测试用例（7组正常+3组异常），然后模拟智能体对每组测试，输出测试报告
  * 适用场景：多文件验证、批量验证、系统验证
  * 示例：生成10组测试用例 → 模拟智能体测试 → 输出测试报告



**方法3：自动化评测**

  * 定义：建立测试集 → 自动运行Agent → 自动打分 → 持续监控
  * 适用场景：生产环境验证、持续监控、自动化验证
  * 示例：建立测试集 → 自动运行Agent → 自动打分 → 持续监控



**重要认知：** 校验工程的核心方法不是"孤立使用"，而是"灵活组合"。一个完整的校验体系可能包含多种方法。 

📖 建立工程化的校验闭环

**建立原则：**

  * **建立标准答案** — 明确正确答案的标准
  * **生成AI输出** — 让AI生成输出
  * **对比差异** — 对比标准答案和AI输出的差异
  * **分析差异原因** — 分析差异产生的原因
  * **迭代优化** — 根据差异原因优化AI



**建立方法：**

第一步：建立标准答案 人工分类10个案例，记录标准答案。 第二步：生成AI输出 让AI分类10个案例，记录AI输出。 第三步：对比差异 对比标准答案和AI输出的差异，记录差异。 第四步：分析差异原因 让AI分析差异产生的原因，记录原因。 第五步：迭代优化 根据差异原因优化提示词，重新测试。

**关键认知：** 建立工程化的校验闭环不是"可有可无"，而是"必须执行"。只有建立了校验闭环，才能保证AI的可靠性。

##### 🧠 认知加油站：Agent评测工程 — 为什么Agent比LLM更难"打分"？（5分钟）

讲师讲解：

我们刚才学的是"人工校验"——自己出标准答案，让AI对照检查。但当你把Agent部署到生产环境后，**不可能每条输出都人工检查** 。你需要一套**自动化评测体系** 。

**为什么Agent评测比普通LLM评测更难？**

  * **不仅要看结果，还要看过程：** 工具调用是否正确？推理链是否合理？
  * **不仅要看对不对，还要看效率：** 用了多少步完成任务？有没有不必要的循环？
  * **不仅要看正常情况，还要看边界：** 输入异常数据时Agent会不会崩溃？



**Agent评测的四个维度：**

维度| 评测什么| 举例  
---|---|---  
结果正确性| 最终输出是否符合预期| 分类结果是否正确？代码是否跑通？  
过程合理性| 工具调用和推理路径是否正确| Agent有没有调用正确的工具？推理步骤是否合理？  
步骤效率| 完成任务所用步数是否最优| 10步能完成的任务，Agent用了30步？  
鲁棒性| 边界情况和异常输入的表现| 空输入是否崩溃？乱码是否误判？  
  
**行业工具：** Ragas（专为RAG系统设计的评测框架）、Arize Phoenix（Agent可观测性与评测平台）、LangSmith（LangChain生态的追踪与评测工具）。这些工具的核心思想都一样：**建立测试集 → 自动运行Agent → 自动打分 → 持续监控** 。

**回到我们的课程：** L18的"三方校验"和"批量用例测试"其实就是**评测工程的手工版** 。当你理解了手工评测的逻辑，自动化评测就是"让AI帮你跑这些测试"。

**一句话记住：** Agent评测 = 不仅要看"答案对不对"，还要看"过程对不对""效率高不高""边界稳不稳"。这是区分"Demo级Agent"和"生产级Agent"的关键能力。
