#### 占位符与保护策略

40分钟 · 融合新增 项目B

##### Part 1：开场导入（5分钟）

讲师开场：

上节课我们学了处理顺序。但有些情况即使顺序对了也会出问题——比如"删除空格"这个操作，**如果`**加粗文字**`中间有空格，删除空格后会变成`**加粗文字**`...等等，这看起来没变？** 但如果是`**"虚实共生、AI驱动"**`——删除空格变成`**"虚实共生、AI驱动"**`，`**`和文字被挤在一起，正则就匹配不到了。

解决方案：**占位符保护** ——在"危险操作"之前，先把重要内容"藏起来"。

##### Part 2：案例剖析 — 第31轮（15分钟）

讲师讲解：

第31轮，学员发现一个诡异的bug：

学员反馈（第31轮）：

`本项目以 **"虚实共生、AI驱动、产训一体"** 为核心理念，构建 **"实体空间+数字孪生+AI大脑"**` 为核心理念，构建 这几个字为什么是倾斜？

原因分析：

问题链条：删除空格 → `**`被拆散 → 斜体正则误匹配了`*` → 输出变成斜体。

**AI的解决方案——占位符保护：**

# 保护加粗语法中的空格 def replace_spaces_in_bold(match): return match.group(0).replace(' ', '\x00').replace('\t', '\x01') line = re.sub(r'\\*\\*.+?\\*\\*', replace_spaces_in_bold, line) line = line.replace(' ', '').replace('\t', '') # 安全删除空格 line = line.replace('\x00', ' ').replace('\x01', '\t') # 还原保护的空格

讲师解读：

三步走：① 先把`**...**`里面的空格替换成特殊占位符（\x00）→ ② 安全删除全文空格（占位符不受影响）→ ③ 把占位符还原为空格。**这就像装修前先把贵重家具用防尘布盖起来。**

📖 占位符与保护策略的概念

**什么是占位符？**

  * 占位符是一种特殊字符，用于临时替代重要内容
  * 占位符的核心是"保护机制"——在危险操作前，先把重要内容"藏起来"
  * 占位符的优势是"安全、可靠、易于还原"



**什么是保护策略？**

  * 保护策略是一种操作流程，用于保护重要内容不被破坏
  * 保护策略的核心是"三步走"——保护→操作→还原
  * 保护策略的优势是"预防级联问题、保证数据完整性"



**关键认知：** 占位符保护 = 在危险操作前藏起来 → 执行操作 → 再还原。这是AI协作开发中处理"冲突操作"的核心技巧。 

📖 占位符保护的设计方法

**设计原则：**

  * **选择占位符** — 选择不会与正常内容冲突的特殊字符
  * **保护内容** — 明确需要保护的内容范围
  * **执行操作** — 执行危险操作，占位符不受影响
  * **还原内容** — 把占位符还原为原始内容



**设计方法：**

在[场景]的项目中，我需要执行[危险操作]。但以下内容中的[需要保护的内容]需要被保护： 1\. [内容1] 2\. [内容2] 3\. [内容3] 请帮我设计一个"占位符保护"策略： \- 使用什么字符作为占位符？ \- 保护→操作→还原的完整流程 \- 有哪些潜在风险？

**关键认知：** 占位符保护的设计不是"可有可无"，而是"必须执行"。只有设计了占位符保护，才能预防级联问题。 

📖 应用占位符保护策略

**应用场景1：Markdown转Word项目**

  * 危险操作：删除所有空格
  * 需要保护的内容：加粗语法`**...**`中的空格
  * 占位符：\x00（空格）、\x01（制表符）
  * 保护流程：替换空格为占位符 → 删除空格 → 还原占位符



**应用场景2：数据处理流水线**

  * 危险操作：删除所有特殊字符
  * 需要保护的内容：日期格式中的特殊字符（如2023-01-01中的-）
  * 占位符：特殊占位符
  * 保护流程：替换特殊字符为占位符 → 删除特殊字符 → 还原占位符



**应用场景3：代码编译流程**

  * 危险操作：删除所有注释
  * 需要保护的内容：代码中的注释标记（如//、/*）
  * 占位符：特殊占位符
  * 保护流程：替换注释标记为占位符 → 删除注释 → 还原占位符



**重要认知：** 占位符保护的应用不是"可有可无"，而是"必须执行"。只有应用了占位符保护，才能保证数据完整性。
